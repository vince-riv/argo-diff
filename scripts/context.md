# scripts/

One script: `prep-release.sh`, the first step of cutting a release.

## prep-release.sh <version>

`scripts/prep-release.sh 2.13.0` rewrites every file that pins the version, then commits the result
as `chore: prep for release <version>`:

| File | What changes |
| ---- | ------------ |
| `charts/argo-diff/Chart.yaml` | `version` and `appVersion` |
| `charts/argo-diff/README.md` | regenerated by `helm-docs` |
| `docs/k8s/kustomization.yaml` | `images[].newTag` |
| `action.yml` | `image: 'docker://ghcr.io/vince-riv/argo-diff:<version>'` |

Requirements and behavior:

- **`helm-docs` must be on `PATH`** (https://github.com/norwoodj/helm-docs) — the script exits early
  if it isn't, rather than committing a stale chart README.
- Takes exactly one argument, a bare version like `2.13.0` (no `v` prefix — release tags in this
  repo are unprefixed).
- Uses `sed -i.bak` and removes the backups; `set -euo pipefail` throughout.
- Exits 0 without committing when nothing changed (already at that version).

## Release flow

1. Run the script on a branch (or main).
2. Merge or push the commit.
3. `git tag -a -s -m 'argo-diff v<version>' <version> && git push origin <version>`.

`.github/workflows/release.yml` then greps `action.yml` for the tagged version and **fails the
release** if the prep commit was skipped, so the tag must point at a commit the script produced.
GoReleaser builds the binaries and image, and the workflow moves the floating `v<major>` and
`actions-v<major>` tags. Tags with a suffix (`2.13.0-rc1`) publish as prereleases.

The Helm chart releases on its own `chart-X.Y.Z` tag — see `charts/context.md`.
